## 一、诊断收口(2026-07-27 收敛)

### 反馈 = 标准答案:卡点在"业务理解 + 关键问题识别"
- 晋升反馈明确:**业务理解 + 关键问题识别**不足。
- 翻译:**你被认可为"能把给定的复杂问题做好"(P8 解题者),但还没被认可为"能定义什么才是值得做的关键问题"(P9 出题者)。** 技术、组织、规模都有,**就差这一个能力**。
- 这是好消息:靶子极其明确,且可刻意练习。

### 旧假设收口
| 旧假设 | 现状 |
|---|---|
| A 叙事不够硬 | 仍存在,但**根因被定位为 B 的下游**:不是不会讲故事,是缺少"关键问题/业务洞察"这个内核。练好"定义问题",叙事自然硬。 |
| B 战略存在感/定义问题 | ✅ **核心卡点确认**。这就是反馈点。 |
| C 赛道天花板 | ✅ **已自解**:离开收缩的海外业务(30→<20 人),移除了无法靠努力改变的变量。**旧公司 4 年没过,部分是赛道问题,不全是你能力问题。** |
| D 班子结构 | 待确认(新公司团队规模/结构未明)。 |

### 新岗位(核心交易平台)是修这个短板的最优解
- **指标最硬、最贴 P&L**:GMV、完单率、匹配效率、抽成、供需平衡、ETA/取消——数据=钱,业务影响最好量化。
- **逼你懂业务**:派单/定价/匹配经济学,做不好就不可能不懂。
- **能见度最高**:核心交易是公司命门,出影响高管直接看见。

> 结论:**换到了"只要补对短板,就最易出 P9 级代表作"的战场。**

### 时序现实:换公司 = 时钟重置
- P8 级别大概率延续,但信任/tenure/scope 要重积累。**正常 12–24 个月**才能冲 P9。
- 现阶段目标:**刻意练"关键问题识别"+ 打出一个量化业务结果代表作**,而非急着答辩。

## 二、管理线 P8→P9 的本质(不变)

| 维度 | P8 管理岗 | P9 管理岗(目标) |
|---|---|---|
| 角色定位 | 交付型:把事做对 | **业务影响型**:定义做对的事 |
| 核心能力 | 解题(给定的复杂问题) | **出题(定义关键问题)** ← 你的靶子 |
| 结果 | 团队交付质量/效率 | 业务域可量化产出 + 组织能力 |
| 业务关系 | 支撑需求 | **代表数据参与业务决策** |
| 能见度 | 一级上级信任 | skip-level 认为"不可替代、必须听" |

## 三、核心打法:刻意练习"业务理解 + 关键问题识别"(从"接活"到"提活")

这是你接下来 12-24 个月唯一要重点练的肌肉。拆成可重复闭环:

1. **钉死北极星**:核心交易平台 top 目标通常是 **GMV / 完单率·体验 / 成本效率** 三选一为主。每个判断都要能挂回它。
2. **找三类信号定位关键问题**:
   - **差距**:目标 vs 现状 / 现状 vs 理论上限——差距大=机会。
   - **反常识**:数据与业务直觉/假设矛盾处——**最有价值的洞察来源**。
   - **瓶颈**:转化漏斗/供需链路卡住的那一环。
3. **把模糊业务问题翻译成"可量化、可归因、可实验"的数据问题**——数据负责人的核心手艺。
4. **每季度主动给业务提 1-2 个"你没问但我发现的关键问题/机会"**,每个带:问题 + 数据证据 + 预估影响 + 建议动作。
5. **复盘命中率**:哪些被采纳/被否/为什么——校准问题嗅觉。

> 练成习惯,1 年内"业务理解+关键问题识别"质变,且**天然产出 P9 代表作素材**。

### 配套动作
- **深度钻业务**:派单/定价/匹配/供需的经济学;跟业务、产品、算法频繁对焦;看业务周报与 KPI 算法。
- **立信任优先**:前 90 天不急着改天换地,先摸清核心交易数据全景 + 建 cross-functional 关系。
- **代表作方向**:一个 data-driven 的业务结果——例:"通过数据定位到匹配效率的 X 问题,推动 Y 优化,完单率/GMV 提升 Z%"。同时治"定义问题"短板 + 业务影响叙事 + 高能见度。

## 四、新公司路径(90天 → 24月)

| 阶段 | 动作 | 产出 |

| **0-90 天:懂业务+建信任** | 摸清核心交易平台数据全景;理解 GMV/效率杠杆;与业务/产品/算法建关系 | 一张"数据全景+业务杠杆地图" |

## 五、答辩要回答的三问题(核心交易域定制)

1. **没有你,核心交易的数据会怎样?**(不可替代 = 战略判断 + 跨域撬动)
2. **你的影响半径?**(域级 + 跨团队证据,业务/算法/产品有人 cite 你)
3. **业务结果量化 + 对齐公司级目标?**(GMV/完单率/效率,而非"做了多少系统")
