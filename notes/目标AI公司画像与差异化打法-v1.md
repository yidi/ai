## 一、先明确你的 4 张"稀缺牌"(决定主攻方向)

1. 🧠 **企业级 Semantic Layer / Ontology / KG 实战**——全市场极少有人真正建过(让 AI 理解业务的语义层)。
2. 📈 **交易策略数据深度**(定价 / 补贴 / 分单 / 供需 / 实验)——极专业,网约车顶级水平。
3. 🏗️ **0→1 建全域数据底座 × 多次 × 跨 4 赛道**(金融/外卖/网约车/短视频直播电商)——建底座的"熟练工"。
4. 🔧 **数据内容 + 产品 + 平台三角**(能亲手建查询引擎/特征平台/实验平台,不止管内容)——行业罕见。

> 结论:你的最优解**不是"任何 AI 公司的数据负责人"**,而是**"需要数据底座支撑 AI / Agent 落地"的公司**——你的牌在这里价值最大、最稀缺。

## 二、5 类 AI 公司 × 匹配度 × 差异化打法

### ⭐ 类型 1:LLM 应用层公司(尤其数据分析 / BI Agent / 企业数据智能方向)—— SWEET SPOT
- **做什么**:基于 LLM 做应用——企业搜索/RAG、智能客服、**数据分析 Agent**、Coding Agent、垂直 Copilot。
- **为什么你最对口**:你现在做的 **AnalystAgent(意图转指标 / 归因 / 洞察)+ 语义层 + 实验评估 + 指标体系**,就是这类公司的核心产品能力。你能直接讲"我在大厂建过生产级的数据分析 Agent 底座"。
- **你怎么赢**:其他候选人要么懂 Agent 不懂数据底座,要么懂数据不懂 Agent+业务。你三者交汇——**"能把 Agent 真正落到企业真实业务数据上"的人极少**。
- **方向词**:数据分析 Agent、AI BI、企业数据智能、NL2SQL/Agent、决策智能。
- **注意**:这是你最强对口,**优先攻**。

### ⭐ 类型 2:AI / 数据基础设施公司(Semantic Layer / 数据治理 / Data&AI 一体化平台)
- **做什么**:向量 DB、特征平台、数据治理、LLM 数据 pipeline、**Semantic Layer as a product**、Data&AI 一体化平台。
- **为什么你最对口**:你建的 **Semantic Layer/Ontology/KG + 数据治理 + 0→1 建底座 = 这类公司的产品核心**。你能讲"我在大厂把这套建过了,知道怎么产品化、怎么卖给企业"。
- **你怎么赢**:**"我不是用过你们的产品,我是亲手在大厂建过同类系统"**——对 infra 公司这是降维打击。
- **方向词**:Semantic Layer(Cube/dbt Semantic Layer 中国对标,正在兴起)、数据 infra、Data&AI 平台、向量检索、数据治理产品。
- **注意**:中国这类公司数量有限、要筛 C/D 轮+,但一旦命中,你的稀缺性溢价最高。

### 类型 3:行业 AI / 垂直大模型公司(出行 / 金融 / 本地生活方向)
- **做什么**:面向特定行业的 AI 解决方案。
- **为什么对口**:你有金融(工行)+ 本地生活(美团)+ 出行(滴滴)多行业数据深度;**出行 AI(智慧出行/自动驾驶数据)是你独有差异化**。
- **你怎么赢**:多行业数据深度 + 0→1 建底座;出行方向你是顶级专家。
- **注意**:面较窄,但出行 AI 是你的"独门武器",可作为差异化选项。

### 类型 4:AI 转型中的中大型公司(数据负责人)
- **做什么**:正在 AI 化的成熟互联网/产业公司,需要数据负责人建 AI-ready 数据底座。
- **为什么对口**:你多次 0→1 建全域底座 + 治理成熟度,对口"帮公司把数据底座升到 AI-ready"。
- **你怎么赢**:稳定 + 建底座熟练;但 comp/股权想象可能不如纯 AI。
- **定位**:可作为**安全网/保底选项**。

### 类型 5:大模型公司(Foundation Model Labs)
- **做什么**:训练基础大模型。
- **匹配度**:中等。大模型公司"数据负责人"更偏**训练数据/eval 数据 pipeline**,你更偏"业务数据底座",部分能力迁移但不完全对口。
- **注意**:角色定义不同,非最强匹配,排在最后。

## 三、主攻排序(按你的匹配度 + 约束)

| 排序 | 类型 | 理由 |
|---|---|---|
| **主攻 1** | LLM 应用层(数据分析/BI Agent 方向) | 最强对口,你正在做的就是它的核心 |
| **主攻 2** | AI/数据 Infra(Semantic Layer 产品化) | 稀缺性溢价最高,降维打击 |
| 备选 | 行业 AI(出行方向) | 独门武器,面窄但差异化强 |
| 安全网 | AI 转型大公司数据负责人 | 稳定保底 |
| 末选 | 大模型公司 | 匹配中等,角色定义不同 |

## 四、筛选标准 + 搜索关键词

**公司阶段筛选(满足你不降薪 + 股票 + 不冒大险)**:
- ✅ C/D 轮以上、有营收、产品已落地;已盈利优先。
- ⚠️ B 轮及以下:慎重,除非赛道/团队/股权极优。
- ✅ 头部大厂的战略级 AI 新业务线也可。

**岗位搜索关键词**:
- 数据负责人 / AI 数据负责人 / Head of Data / VP Data / 数据总监
- 数据平台负责人 / 数据架构师(资深)/ 数据基础设施负责人
- AI Data / Data & AI / Analytics Engineering 负责人
- BI Agent / 数据分析 Agent / 决策智能 团队负责人

**地域**:北京为主;上海/杭州/深圳/远程视机会。

## 五、按面试场景的差异化话术

| 场景 | 你怎么讲 |
|---|---|
| 对**应用层/Agent 公司** | "我在大厂建过生产级数据 Agent 底座(AnalystAgent + 语义层),知道怎么让 Agent 真正跑在企业数据上——这恰恰是你们卡住的地方。" |
| 对**Infra/平台公司** | "你们在做产品的 Semantic Layer/数据治理,我亲手在大厂建过同类系统,我能告诉你们企业真实要什么、怎么落地。" |
| 对**出行/行业 AI** | "我有出行交易策略最深的数据经验(定价/补贴/分单/实验),这是你们做行业 AI 最缺的。" |
| 对**大公司数据负责人岗** | "我多次 0→1 建全域底座 + 治理成熟,能把你们的数据底座升到 AI-ready。" |
| 万能收尾 | "我的独特性在数据工程 × 业务策略 × AI/Agent 的交汇点——能把企业数据资产建成 AI 可消费的智能底座。" |
